# Download the documentation

Everything for this build is in this GitHub repository.

1. On the repository front page, click **Code → Download ZIP**, or run `git clone https://github.com/ToolKnox/hawkridge-cloudy-mk2-mini-agv-ros2-robot.git`.
2. Start with the root `README.md`. It opens with the install and build guide.
3. Print files, firmware and the original robolaunch documentation are mirrored under `source/upstream/`.
4. The full ROS 2 workspace is in https://github.com/robolaunch/cloudy (commit `a15f636`).
